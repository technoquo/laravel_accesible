## What it requires

Any keyboard-operable interface must show a visible indicator of the element that has focus.

## Why it matters

Without a focus indicator, keyboard users do not know where they are: it is like using a mouse without seeing the pointer.

## How to meet it in Laravel

Never remove the focus outline without putting something in its place. This blog defines a global indicator in `app.css`:

```css
@layer base {
    *:focus-visible {
        outline: 2px solid currentColor;
        outline-offset: 3px;
        border-radius: 2px;
    }
}
```

`:focus-visible` shows the indicator when navigating with the keyboard, not when clicking with the mouse.

In components, if you use Tailwind's `focus:outline-none`, always add a visible replacement:

```blade
<button type="submit"
        class="rounded bg-gray-900 px-4 py-2 text-white
               focus:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-gray-900">
    Save
</button>
```

Make sure the indicator is also visible in dark mode and high-contrast modes: using `currentColor` helps, because it follows the text colour.

## Common mistakes

- `outline: none` in a global CSS reset.
- `focus:outline-none` without a `ring` or other focus style.
- An indicator the same colour as the background in one of the themes.

## How to test it

- **Manual:** go through the page with `Tab` in each theme (light, dark, high contrast) and check that you can always see where focus is.
- **Automated:** axe does not check this criterion. You can take Playwright screenshots of the focused element to review them.
