## What it requires

At a width of **320 CSS px** —equivalent to zooming a 1280 px window to 400%— content must be readable and usable without scrolling in two directions. On a vertically scrolling page, no horizontal scrollbar should appear.

Content that needs a two-dimensional layout to be understood is exempt: data tables, maps, diagrams, video or games.

## Why it matters

People with low vision enlarge text a lot. If every line then requires scrolling left and right, reading becomes exhausting and it is easy to lose your place.

## How to meet it in Laravel

Design mobile-first with Tailwind CSS and let content adapt:

```blade
<div class="mx-auto max-w-5xl px-4">
    <div class="flex flex-wrap gap-4">
        <div class="min-w-0 flex-1">
            <h2 class="break-words">{{ $post->title }}</h2>
        </div>
    </div>
</div>
```

- Avoid fixed widths in px; use `max-w-*`, percentages and `flex-wrap`.
- Add `min-w-0` to flex children with long text, and `break-words` for URLs or very long words.
- Data tables can scroll inside their own container without dragging the page along:

```blade
<div class="overflow-x-auto" tabindex="0" role="region" aria-label="Articles table">
    <table>...</table>
</div>
```

The container gets `tabindex="0"` so it can be scrolled with the keyboard. This blog does the same with code blocks (`<pre tabindex="0">`).

## Common mistakes

- Horizontal menus that do not collapse on narrow screens.
- Images or videos with a fixed width (use `max-w-full h-auto`).
- `white-space: nowrap` on long titles or buttons.

## How to test it

- **Manual:** set the window to 1280 px wide and zoom to 400%, or use DevTools' responsive mode at 320 px; go through every page.
- **Automated:** axe does not check it, but you can measure it with Playwright:

```js
await page.setViewportSize({ width: 320, height: 800 });
await page.goto('/en');
const hasHorizontalScroll = await page.evaluate(
    () => document.documentElement.scrollWidth > document.documentElement.clientWidth
);
expect(hasHorizontalScroll).toBe(false);
```
