## What it requires

All non-text content that conveys information or has a function —images, icons, charts, image buttons— needs a text alternative that serves the same purpose. Purely decorative images must be ignorable.

## Why it matters

A screen reader cannot describe an image: it reads its alternative. Without one, it announces the file name or nothing at all, and the person loses the information or does not know what a button does.

## How to meet it in Laravel

First decide what role the image plays:

- **Informative:** the `alt` describes what it conveys, not what it looks like.
- **Functional** (inside a link or button): the `alt` describes the action or destination.
- **Decorative:** `alt=""` so assistive technology ignores it.

```blade
{{-- Informative --}}
<img src="{{ $chart->url }}" alt="Monthly visits: growing from 1,200 in January to 3,400 in June">

{{-- Functional: the alt describes the destination, not the logo --}}
<a href="{{ route('home', ['locale' => app()->getLocale()]) }}">
    <img src="/logo.svg" alt="Laravel Accesible, home">
</a>

{{-- Decorative --}}
<img src="/ornament.svg" alt="">
```

For SVG icons inside buttons, hide the icon and provide the name as text:

```blade
<button type="button" wire:click="delete({{ $post->id }})">
    <svg aria-hidden="true" focusable="false"><!-- ... --></svg>
    <span class="sr-only">Delete "{{ $post->title }}"</span>
</button>
```

If editors upload images from an admin panel, make the alternative text a form field and validate it, with an explicit option to mark the image as decorative.

## Common mistakes

- `alt="image"`, `alt="photo"` or the file name.
- An `alt` that repeats the text right next to it (the reader reads it twice).
- An `alt` that describes a different photo from the one shown, for example with random placeholder images.
- Icon-only buttons without a name.

## How to test it

- **Automated:** axe detects images without `alt` and SVGs with `role="img"` and no name, but it cannot tell whether the text is correct.
- **Manual:** read each `alt` without looking at the image and ask whether it conveys the same thing; go through the page with a screen reader and check that icon buttons announce their action.
