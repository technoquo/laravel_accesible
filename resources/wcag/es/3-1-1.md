## Qué exige

El idioma principal de cada página tiene que poder determinarse por programa, es decir, estar indicado en el atributo `lang` del elemento `<html>`.

## Por qué importa

Los lectores de pantalla eligen la voz y las reglas de pronunciación según el idioma declarado. Si una página en español se declara en inglés, el texto se lee con acento inglés y resulta casi incomprensible. También lo usan los traductores automáticos, los diccionarios y los correctores.

## Cómo cumplirlo en Laravel

El layout que genera Laravel ya lo hace a partir del idioma de la aplicación:

```blade
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
```

En un sitio bilingüe, fija el idioma **antes** de renderizar la vista; por ejemplo, con un middleware que lo lea de la URL:

```php
// app/Http/Middleware/SetLocale.php
public function handle(Request $request, Closure $next): Response
{
    $locale = $request->route('locale');

    abort_unless(in_array($locale, ['es', 'en'], true), 404);

    app()->setLocale($locale);

    return $next($request);
}
```

Usa códigos de idioma válidos (`es`, `en`, `es-CR`, `en-GB`) y no los nombres de los archivos de traducción si no coinciden con un código BCP 47.

## Errores frecuentes

- Dejar `lang="en"` fijo en un layout que también sirve contenido en español.
- Cambiar el idioma después de que la vista ya se haya empezado a renderizar.
- Códigos inválidos como `lang="spanish"` o `lang="es_ES"` con guion bajo.

## Cómo probarlo

- **Automático:** axe comprueba que `<html>` tiene `lang` y que el valor es válido (`html-has-lang`, `html-lang-valid`, `html-xml-lang-mismatch`). Con Pest puedes comprobarlo en cada idioma:

```php
test('la página declara su idioma', function (string $locale) {
    $this->get("/{$locale}")->assertSee('<html lang="'.$locale.'"', false);
})->with(['es', 'en']);
```

- **Manual:** escucha la página con un lector de pantalla y comprueba que la pronunciación es la del idioma correcto.
