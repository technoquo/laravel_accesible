## Qué exige

Con un ancho de **320 px CSS** —lo que equivale a ampliar al 400 % una ventana de 1280 px— el contenido se tiene que poder leer y usar sin desplazamiento en dos direcciones. En una página que se desplaza en vertical, no debe aparecer scroll horizontal.

Quedan fuera los contenidos que necesitan una disposición bidimensional para entenderse: tablas de datos, mapas, diagramas, vídeos o juegos.

## Por qué importa

Las personas con baja visión amplían mucho el texto. Si al hacerlo cada línea obliga a desplazarse a izquierda y derecha, leer se vuelve agotador y es fácil perderse.

## Cómo cumplirlo en Laravel

Diseña con Tailwind CSS partiendo del móvil y deja que el contenido se adapte:

```blade
<div class="mx-auto max-w-5xl px-4">
    <div class="flex flex-wrap gap-4">
        <div class="min-w-0 flex-1">
            <h2 class="break-words">{{ $post->title }}</h2>
        </div>
    </div>
</div>
```

- Evita anchos fijos en px; usa `max-w-*`, porcentajes y `flex-wrap`.
- Añade `min-w-0` a los hijos de un contenedor flex que tengan texto largo, y `break-words` a URLs o palabras muy largas.
- Las tablas de datos pueden desplazarse dentro de su propio contenedor, sin arrastrar la página:

```blade
<div class="overflow-x-auto" tabindex="0" role="region" aria-label="Tabla de artículos">
    <table>...</table>
</div>
```

El contenedor recibe `tabindex="0"` para poder desplazarse con el teclado. Este blog hace lo mismo con los bloques de código (`<pre tabindex="0">`).

## Errores frecuentes

- Menús horizontales que no se pliegan en pantallas estrechas.
- Imágenes o vídeos con ancho fijo (usa `max-w-full h-auto`).
- `white-space: nowrap` en títulos o botones largos.

## Cómo probarlo

- **Manual:** pon la ventana a 1280 px de ancho y amplía al 400 %, o usa el modo responsive de DevTools a 320 px; recorre todas las páginas.
- **Automático:** axe no lo comprueba, pero puedes medirlo con Playwright:

```js
await page.setViewportSize({ width: 320, height: 800 });
await page.goto('/es');
const hasHorizontalScroll = await page.evaluate(
    () => document.documentElement.scrollWidth > document.documentElement.clientWidth
);
expect(hasHorizontalScroll).toBe(false);
```
